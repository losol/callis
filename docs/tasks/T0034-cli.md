# T0034 — CLI (optional)

Part of the [roadmap](../roadmap.md). Phase 3 · wave 8 · size M.

- **Depends on:** [T0038](T0038-public-api-completion.md)
- **Area:** `area:tooling`
- **Tier hint:** likely `risk:high`: a new package with its own dependencies, so the standard tier. Add `packages/cli` to an area in `scripts/review-areas.ts`.

## Goal

`@callis/cli` with:

- `callis eval '<expr>' file.json [--model r4|r5|r6] [--typed] [--var name=value]`
- `callis parse '<expr>'` (prints the AST)
- `callis check '<expr>' --type Patient [--model r4|r5|r6]` (runs the analyzer)

`--model r6` uses the pinned `6.0.0-snapshot1` draft provider; the help text and README say so ([FHIR versions](../roadmap.md#fhir-versions)).

## Acceptance criteria

Works through `npx`; output is JSON or human-readable; errors are formatted with a source excerpt; exit codes are documented; `--model` accepts `r4`, `r5` and `r6`, each tested.
