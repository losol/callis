## Reproducible artifact checks

- `pnpm check` builds and applies publint, attw, runtime-dependency and compressed-size gates for all four packages. Its packed core/UCUM consumer now always includes `--operators`, covering arithmetic, quantities, provider identity and synchronous error guards.
- `pnpm check:release` builds all four, packs actual archives, installs them together into a fresh Node project with **offline strict peer resolution**, typechecks the declarations, then executes one shared contract under Node ESM and in a fresh Vite production build in Chromium. It uses no workspace aliases or registry substitutes. The CI site job runs it after installing Chromium.
- `pnpm check:release --stable` additionally copies package/config/changeset inputs to a temporary directory, reuses pinned tooling, records exit intent if needed and runs version generation there. It asserts stable manifests and matching changelog headings, then installs/tests those actual tarballs. It never invokes a publish command, workflow or staged publication. Generated changelogs remain untouched in the checkout.
- Tarball assertions require README, ESM, declarations, exact export maps, full MIT texts and unchanged source notices. This preparation fixes previously missing MIT files in core/R4/R5 archives, and explicitly includes generated changelogs in all four `files` lists. Patch changesets cover those user-visible packaging/docs changes; existing minors still produce 0.1.0.
- The consumer exercises navigation, compile, empty output, exact decimal arithmetic/Quantity strings, unsupported-function diagnostics, UCUM kg→g conversion with the **same Decimal class**, and immutable R4/R5 type/choice metadata. Existing packed checks additionally verify named error classes and source maps.
- README/guide code is shared through `examples/public-api.ts` and executed by `public-docs.test.ts`; the site consumes the same guide. The handwritten guide and TSDoc are sufficient for this small release; generated API reference remains T0038 work.

Chromium must already be installed for the browser smoke (CI does this). The deliberately combined all-four model/UCUM Vite fixture produces a large-chunk advisory; this is not the core compressed-size budget or the lazily loaded playground route cost. No new size threshold is introduced. Current measured checks, tarball byte counts/integrities and exact covered commits belong in the PR's maintained validation comment, not in this durable release plan.
