Add `@callis/ucum`, full UCUM unit conversion as a `UnitSystem`: prefixes, every unit of the UCUM essence file, unit expressions with annotations and `10*n`, exact conversion, `Cel` and `[degF]`, and unit algebra for `*` and `/`. The package embeds the unchanged `ucum-essence.xml` (UCUM License, Version 1.1; see `SOURCE.md`) and reads it when first imported. It has no runtime dependencies.
